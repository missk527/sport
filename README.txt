YOUR HEALTH APP

This is an installable web app (PWA).

Upload ALL files in this folder to the same HTTPS website.

iPhone / iPad:
1. Open sport.html from the hosted website in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Your health will appear like an app.

Android:
1. Open sport.html from the hosted website in Chrome.
2. Tap the menu.
3. Choose Install app or Add to Home screen.

The Collaborative Hong Kong Women logo is embedded inside sport.html.
The Your health icon is used for the phone home-screen app icon.
